# JLSH 月报配置与样报生成演示

84 秒、1920×1080、30 fps 的中文产品演示。以真实产品截图为证据，采用独立可编辑 Remotion 场景、清晰字幕与节奏化转场。使用 10 张经过裁剪与实心遮挡的真实产品截图，已完成字幕与轻量转场。画面是截图动效，不伪装成点击操作录屏。

## 真实性与公开范围

- 全片持续标注“模拟数据演示”。不将模拟数据包装成真实经营成果。
- 不是完整六章技术月报，不承诺正式发布、入库或跨期复用完成。
- 经理/员工读取样报仍有 403；不宣称三角色业务闭环。

- 仅纳入逐张检查的脱敏截图；原始录屏、原始数据、账号、内部标识及凭据不得提交。

## 运行

Node.js 环境执行 `npm ci`，然后 `npm run studio` 启动 Remotion Studio。

常规 Chromium 渲染：`npm run render`。

云环境不能启动 Chromium 时，可运行 `npm run render:offline`，以同一 React/SVG 组件经 resvg 与 FFmpeg 导出，不需浏览器服务。要求本机有 FFmpeg 和支持中文的 Noto Sans CJK 字体。

`npm run check` 验证 TypeScript。`node scripts/render-offline.cjs --previews` 输出逐场景审阅图。缺少实际截图时，导出脚本会中止，防止占位画面混入成片。

最终视频为无声字幕版本；没有使用未获授权的配乐或克隆声音。

## 文件

- `public/assets/`：10 张公开安全衍生截图，保留完整模拟数据与候选环境页脚。
- `public/storyboard.json`：仅公开分镜、时长、文案与事实边界，无本机来源路径。
- `public/narration.srt`：可供后续配音的字幕脚本；本版本没有音轨。
- `out/jlsh-monthly-report.mp4`：最终 H.264 视频。
- `out/poster.png`：视频封面帧。

不包含原始上传 ZIP、原始日志、数据或本机核验清单。
